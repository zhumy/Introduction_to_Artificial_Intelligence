## 打开与发布

下载完整目录后，打开 index.html。图片、音频和脚本使用相对路径，请保持 assets 和 style.css 与 index.html 的目录关系。

提交 GitHub 时上传本目录内全部文件。在仓库 Settings → Pages 中选择从分支部署，选择 main 分支与根目录。发布完成后通过 GitHub Pages 地址访问。
