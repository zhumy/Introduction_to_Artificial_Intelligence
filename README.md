# Introduction to Artificial Intelligence

苏州大学《人工智能概论》课程材料。课程面向大学一年级或二年级学生，以概念、历史、方法、应用与未来为主线组织。

## 使用方法

克隆仓库后直接打开 `index.html`。图片和音频均使用相对路径；请保留 `assets` 目录。

## 内容

- `index.html`：完整课程页面
- `assets/core`：课程前段图像和音频
- `assets/extended`：课程后段图像和音频
- `COURSE_MAPPING.md`：课程内容与课件文件对应关系

视频因 GitHub 免费账户的存储与带宽限制未收入本仓库；原始课程包中的图片和音频均予以保留。
